# apaw MCP 金融研究服务

> 一套面向 AI 的金融研究工具集：让你的 AI 客户端（Claude、Cline、Cherry Studio 等）直接查行情、跑技术分析、判市场状态、做因子选股——用自然语言驱动机构级的研究流程。

## 服务信息

| 项目 | 内容 |
|------|------|
| 接口地址 | `https://mcp.apaw.cc/mcp` |
| 协议 | MCP（Streamable HTTP） |
| 鉴权 | Bearer Token（`sk-` 开头） |
| 限流 | 480 次 / 60 秒 |
| 接入方式 | 客户端填一行配置，或开发者直调 JSON-RPC |

## 核心能力（70 个工具 · 5 大域）

### 1. Cross-Market — 跨市场行情（15 工具）
A股/港股/美股主要指数、170+ 法币汇率、外汇货币对、加密货币（Gate.io）、国内期货（新浪），支持单查与批量，内置 10 分钟缓存降低重复请求。

### 2. pvanalysis — 价量技术分析（36 工具）
多维价量分析引擎：趋势强度、量能结构、K线形态、价量背离（四维交叉验证）、突破防操纵过滤、顶部风险、底部综合信号、多周期共振、成交量分布（POC/价值区）、VSA 四象限、撮合段/尾盘专项分析、板块匹配评分、宏观环境判定。
**全市场批量扫描**：16 路并发，4500 只标的一次调用约 10 秒。

### 3. market_regime — 大盘状态分类（6 工具）
指数市场环境 6 状态分类器 + 5 维特征向量、多指数批量对比、周期节奏排除法推演，以及异步自调参（后台 10-15 分钟/指数，任务制查询进度）。

### 4. stock_emb — 因子选股（8 工具）
市场阶段五分类（强牛/震荡牛/震荡/震荡熊/熊市）并推荐当期适配因子；按因子取候选标的；250 日三窗口轨迹快照；**因子 ∩ 轨迹交集过滤**（一步出最终候选）；峰谷节奏波段骨架分析。

### 5. fin_new — 新闻与复盘（7 工具）
环境综合成果（五级体系）、外部复盘文档、单篇新闻原文 + 分析，支持从结论逐层溯源下钻到原文。

## 特点

- **AI 原生设计**：每个工具输出结构化结果，AI 可直接消费；每个域自带 `*_readme` 工具，接入后 AI 自己就能读懂全部参数，无需人工喂文档。
- **批量优先**：绝大多数分析工具都有 `_batch` 版本，一次调用处理全市场，不做 N 次循环。
- **研究链路完整**：宏观环境 → 大盘状态 → 全市场扫描 → 因子选股 → 个股价量确认 → 新闻溯源，一条链在同一个 MCP 会话里跑完。
- **持续自调参**：market_regime 支持后台重新校准，参数不是一锤子买卖。

## 典型用法

```
你：帮我看看今天大盘什么状态
AI：调用 market_regime → 震荡市，量能收缩，建议观望

你：在震荡市因子里帮我筛 30 只，看价量确认
AI：emb_candidates → emb_batch_trajectory → pv_full_batch，输出带评分的候选表

你：挑出来的这只最近资金流怎么样
AI：pv_fund_flow_trend → pv_bottom，给出结论
```

## 接入

在任意支持 Streamable HTTP 的 MCP 客户端中配置：

```json
{
  "mcpServers": {
    "apaw-finance": {
      "url": "https://mcp.apaw.cc/mcp",
      "transport": "streamableHttp",
      "headers": { "Authorization": "Bearer <你的密钥>" }
    }
  }
}
```
